# Changelog

## 2026-08-14

- Удаление снимка в редакторе стало автосохраняемым и отменяемым черновым действием; фактическое удаление выполняется только общей публикацией.
- Убрана ручная кнопка сохранения черновика, сохранены индикатор автосохранения, отмена и публикация.
- Уже добавленные TIFF в каталоге снимков отмечаются зелёной рамкой и недоступны для повторного выбора; добавление папки пропускает их.
- Тестовые разметки переведены на уровень класса при сохранении исходного датасета как происхождения тайлов; основная разметка теперь одна на класс.
- Метрики и матрица сетей охватывают все датасеты класса и явно показывают сеть и её обучающий датасет.
- При отсутствии псевдоразметки исходного датасета редактор предлагает идемпотентно запустить её текущей основной сетью.
- Исполнитель тестового F1 принимает основную разметку класса для сетей `main_new`, `test`, `strict` и других датасетов того же класса, не требуя совпадения исходного датасета тайлов с датасетом обучения.

## 2026-08-04

- Плагин версии 0.3.0 подсвечивает текущий кандидат и синхронно фильтрует очередь и слой по минимальной площади и уверенности.
- Сервер возвращает confidence объекта из пиксельных вероятностей модели; для перекрывающихся снимков сохраняется максимальная уверенность наблюдения.
- В интерфейсе подключения оставлена одна кнопка; URL и пользователь `mlsystem` зафиксированы, пароль разворачивается только в локальный профиль QGIS.
- Плагин версии 0.3.1 открывает новый результат на непроверенных кандидатах, объясняет пустой отбор и показывает идентификатор загруженного задания.
- Плагин версии 0.3.2 сразу убирает с карты старые слои кандидатов при запуске нового распознавания, сохраняя их GeoPackage.

## 2026-08-03

- Добавлен серверный AOI API для QGIS с фиксацией последней пригодной модели, пространственным отбором TIFF и общей очередью инференса.
- Псевдоразметка обрабатывается только в пересекающих AOI окнах, обрезается по AOI и возвращается как FeatureCollection со стабильными candidate_id и метаданными покрытия.
- Добавлен отдельный QGIS-плагин с неблокирующим HTTP, постоянным GeoPackage staging, явно выбранными целевыми слоями и сопоставлением полей.
- Решения проверки и разбиение полигонов получили единый QUndoStack; применение в два слоя проверяет candidate_id и не создаёт дубликаты.
- Добавлены серверные, чистые Python и headless QGIS 4.0 тесты, а также документация API, установки и ручной проверки.
- Плагин версии 0.1.1 использует обычный вход MLSystem вместо ручного Bearer-токена; адрес `https://grovika.ru` и пользователь `mluser` заполнены по умолчанию.
- Плагин версии 0.2.0 показывает геодезическую площадь AOI, не ограничивает её размер по умолчанию и автоматически сопоставляет схему `fid` + `Classname` без требования поля candidate_id.

## 2026-07-30

- Исправлено восстановление полигонов, становящихся невалидными после преобразования CRS при расчёте тестового F1.
- Расширенный пул сохраняет последнее допустимое решение при тайм-ауте вторичной MILP-оптимизации, а невозможные ограничения показывают достижимый максимум объектов с учётом конфликтов тайлов.
- Одиночное и групповое скачивание тестовых разметок предлагает режим с превью либо только с TIFF и GeoJSON.
- Групповой архив принимает явный список разметок, готовит до восьми одновременно и собирает все записи без сжатия.
- Папки группового архива получили стабильные имена `<класс>_<датасет>` без даты; неоднозначный выбор нескольких разметок одного датасета отклоняется.
- Окно группового выбора стало компактным вертикально прокручиваемым списком в три колонки с датой и звездой основной разметки.
