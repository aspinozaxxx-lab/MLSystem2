# MLSystem 2.0

MLSystem 2.0 — минимальная система обучения и инференса, запускаемая из командной строки.
Имя пакета — `mlsystem2`, чтобы проект не конфликтовал со старым MLSystem.

В репозитории остается только необходимое и достаточное: типизированные настройки,
контракты подготовки датасета, контракты источников тайлов, контракты моделей и
чекпойнтов, метрики, оркестрация обучения, оркестрация инференса и один адаптер MLflow.
MLSystem2 работает с локально подготовленными снимками; серверная папка prepared-снимков:
`/data/mlsystem2/prepared_images/kanopus/`.

## Отличие от старого MLSystem

Старый MLSystem можно использовать только как источник идей и доменной логики для следующих шагов
миграции. Инфраструктура из старого проекта сюда не переносится.

В этом репозитории есть отдельный минимальный FastAPI-модуль `training_ui_api` и статический
`frontend` для запуска обучения и просмотра очередей/результатов. Эйрфлоу, Рэббит-эм-кью,
Тритон-сервер, Докер, Докер-компоуз, Ансибл, Графана и Прометей в MLSystem2 не переносятся.
Ссылки на Grafana, MLflow и MinIO отдаются через UI API.

## Запуск

```bash
pip install -e .[dev]
mlsystem2-train --config configs/example.local.yaml
mlsystem2-infer --config configs/example.local.yaml
```

Frontend собирается без Node.js:

```bash
python frontend/build.py
```

Ручное развертывание Postgres и UI-сервиса описано в
`docs/runbooks/training_ui_infrastructure.md`.
