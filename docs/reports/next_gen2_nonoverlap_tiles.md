# Нарезка next-gen2 без нахлёста

8 сентября 2026 года по запросу пользователя обучение переведено с сетки 512/256 на полные тайлы
512×512 без нахлёста. Шаг всегда равен размеру тайла: это правило применяется в настройках,
подготовке данных и сохранении шаблона; отдельное поле шага скрыто в интерфейсе next-gen2.
Нормализация, разметка, sampler и веса классов остаются прежними. Аугментации пока выключены.

Validation выбирается детерминированно по доле из конфига, по умолчанию 20%. Доля рассчитывается
среди фактически оставшихся train и validation после исключения пересечений. Подбирается число
первых тайлов в порядке SHA-256 с ближайшим достижимым соотношением целых окон.
Внутри TIFF общих пикселей нет, однако разные
TIFF могут покрывать одну территорию. Поэтому проверка общей площади между train и validation
сохранена; касание границ допустимо. Полные окна не дополняются по краям и не сдвигаются к границе TIFF.

Независимая проверка на 14 снимках `Переувлажнения\test_ml`, версия
`managed:1:git:757b1fad03ddc311a24088f2c29c246f0378d810`:

| Показатель | Значение |
|---|---:|
| Все полные окна | 7367 |
| Кандидаты train | 6114 |
| Validation | 1253 |
| Исключены из train из-за пересечений разных TIFF | 1104 |
| Оставшиеся train | 5010 |
| Итоговое соотношение train / validation | 79,9936% / 20,0064% |
| Снимки в каждой выборке | 14 |
| Train-окна, пересекающие validation после исключения | 0 |
| Train-окна с долей объекта >0,001 | 114 |
| Validation-окна с объектной разметкой | 30 |

Всего используется 6263 тайла. `round(6263 × 0.2) = 1253`: доля из конфига соблюдена
с округлением до целого тайла. Предварительный выбор 20% до исключений давал 1473 validation
и 4677 train (23,95% validation); этот порядок расчёта исправлен до нового запуска.

Географические прямоугольники независимо восстановлены из TIFF; проверены раздельность индексов,
отсутствие общей площади и выбор sampler только из оставшегося train. Веса CrossEntropy
`[0.0016368116484954953, 1.9983631372451782]` рассчитаны только по этому train.
Прежняя сетка после исключения оставляла 2719 train против 5856 validation.

Параметры нового запуска и шаблона: 300 эпох, не более 10800 секунд, batch 32, ранняя остановка
после 50 эпох без улучшения F1, best по F1, начало с исходных предобученных весов и автоматическая
псевдоразметка после обучения. Инференс сохраняет сетку eval-ноутбука 512/256, гауссово объединение
и порог строго >0,9. Правила legacy и первого next-gen не изменены.
