# Перенос исходного обучения в next-gen2

Источник: `G:\Мой диск\Айтеко\NewPipeline\train_full_pipeline_заболачивание.ipynb`.
Неизменяемая копия для проверок: `tests/fixtures/next_gen2_train.ipynb`.
SHA-256: `165157276ae777ef9e7538b7daead9d27cb8dc42c8bdf8225278b40defd5a5f4`.

В интерфейсе обучения выбираются **SegFormer B0 HF → Вариант конвейера → next-gen2**.
При переключении подставляются исходные параметры ноутбука; выбор сохраняется в обычных шаблонах.
Бинарные датасеты Канопуса используют штатный каталог и неизменяемый снимок разметки задания.
Пути и сопоставление TIFF/GeoJSON определяет система; локальный префикс `irkutsk_` не требуется.

| Часть | Поведение next-gen2 |
|---|---|
| Нарезка | Полные окна 512×512, шаг 256; без дополнения краёв, контекста, фильтрации чёрных окон и аугментаций |
| Разбиение | Два последовательных разбиения с seed 42, 60/20/20; порядок и индексы записываются в артефакты |
| Тестовая часть | Резервируется, не влияет на обучение или выбор лучшей эпохи; исходный train-ноутбук её также не оценивает |
| Нормализация | Min-max каждого канала каждого окна; постоянные каналы обнуляются; nodata включается |
| Выбор тайлов | С возвращением, вес 15 при доле объекта >0.001, иначе 1; число выборок равно размеру train |
| Модель | Предобученная HF SegFormer B0, выходы для двух классов, RGB→RGB и RED→NIR; случайное смещение новой входной свёртки |
| Обучение | Взвешенная CrossEntropy, веса только по train; AdamW, LR 1e-4, weight decay 0.01; без ограничения нормы градиента |
| Валидация | Полная каждую эпоху; средняя ошибка учитывает размер последнего пакета |
| Остановка и лучшие веса | Минимум validation loss; patience 9; ReduceLROnPlateau с patience 3 и factor 0.5 |
| Исходный запуск | Batch 8, максимум 50 эпох; сервер использует 8 workers, исходный ноутбук — 0 |

Размер/шаг окна, batch, число эпох, LR, weight decay, patience и ограничение времени можно менять.
Нормализация, разбиение, sampler и функция потерь закреплены за вариантом. Перекрывающиеся тайлы могут
попадать в разные части, как в ноутбуке; такая валидация не является независимой оценкой по территориям.
Инициализация случайных генераторов и закреплённая версия HF-весов добавляют воспроизводимость:
исходный ноутбук фиксировал только случайность разбиения, но не Torch и версии библиотек.

Обучение получает оба logits без алгебраического преобразования loss. Для штатного бинарного инференса
модель возвращает их разность: sigmoid этого выхода соответствует вероятности объекта двухклассовой
softmax. Это сохраняет существующий контракт модели, экспорт, псевдоразметку и контрольные оценки.
F1 в результатах относится к эпохе сохранённых лучших весов, даже если максимальная F1 была в другой эпохе.
Нарезка и обучение `legacy`, а также существующий `next-gen`, сохраняют прежнее поведение.

## Запуск через командную строку

Пример исходного профиля находится в `configs/run.next-gen2.server.yaml`:

```bash
mlsystem2-train --settings configs/settings.server.yaml --run configs/run.next-gen2.server.yaml
```

Перед запуском задайте свой опубликованный бинарный датасет в `dataset.annotations_dir`.
