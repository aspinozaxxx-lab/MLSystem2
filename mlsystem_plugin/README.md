# QGIS-плагин MLSystem2

Плагин запускает серверное распознавание AOI, фильтрует найденные полигоны, разбивает крупные
объекты и выгружает текущий отбор в новый слой QGIS. Он не изменяет существующие слои проекта и
не отправляет на сервер снимки, WMS, скриншоты или клиентские пути: тело задания содержит только
`class_id`, `source_id`, GeoJSON AOI и её CRS.

## Совместимость и установка

Метаданные разрешают QGIS `3.34–4.x`. Автоматическая проверка выполняется в QGIS
`4.0.0 Norrköping`, Qt `6.8.1`. Установленная копия находится в каталоге профиля:

```text
C:\Users\Олег\AppData\Roaming\QGIS\QGIS4\profiles\default\python\plugins\mlsystem_plugin
```

Для ручной установки скопируйте туда всю папку `mlsystem_plugin`, затем включите
«MLSystem2 — распознавание объектов» в менеджере плагинов.

## Подключение и пароль

Плагин автоматически подключается к `https://grovika.ru` под пользователем `mlsystem` и загружает
классы. Пароль не входит в репозиторий и не находится в папке плагина. Он хранится через
`QgsSettings` в локальном файле профиля QGIS:

```text
C:\Users\Олег\AppData\Roaming\QGIS\QGIS4\profiles\default\QGIS\QGIS4.ini
```

В файле используется секция `[mlsystem2]` и параметр `pseudolabel\password`. Токен пользователю
не нужен. Успешное подключение видно по заполненному списку классов.

## Область интереса и распознавание

1. Выберите класс и источник снимков. По умолчанию выбирается тип обучающего датасета основной сети.
2. Проверьте подсказку о типе модели, числе каналов, разрешении и возможном нулевом NIR.
3. Нажмите «Нарисовать AOI» и добавляйте вершины левой кнопкой мыши.
4. Нажмите «Использовать эту AOI». Контур останется видимым, а в панели появится его площадь.
5. Для сброса черновика нажмите правую кнопку мыши: инструмент останется активным и позволит
   начать с первой вершины.
6. Нажмите «Запустить распознавание».

Запросы выполняются через Qt Network без блокировки интерфейса. В панели показываются этап,
прогресс, загрузка внешних снимков, подготовка разрешения, число выбранных сервером TIFF и
фактическое покрытие AOI. Доступны Канопус, ортофото, OpenAerialMap и настроенные сервером
XYZ/TMS/WMTS. Произвольная подложка проекта остаётся только визуальной и на сервер не передаётся.

## Фильтрация, разбиение и выгрузка

Для каждого задания создаётся локальный `pseudolabel_<job_id>.gpkg` со слоем `candidates`.
Минимальная площадь и минимальная уверенность сразу фильтруют и очередь, и видимые полигоны.
Текущий объект выделяется жёлто-фиолетовой подсветкой; доступны переходы, приближение и сортировка
по исходному порядку, уверенности или площади.

«Разбить текущий» делит выбранный объект, а «Разбить все крупные» — все прошедшие текущие фильтры
объекты, площадь которых больше «Макс. площадь части». Разбиение выполняется в локальной
равноплощадной CRS рекурсивно по длинной стороне bounding box. Исходный родитель скрывается,
части получают `parent_candidate_id`, стабильные UUID и наследуют атрибуты исходного объекта.

«Выгрузить на новый слой» создаёт новый временный слой QGIS. В него попадают только полигоны,
которые в момент нажатия проходят фильтры площади и уверенности. Если объект был разбит, выгружаются
его части, а не исходный родитель. Существующие слои и их схемы не изменяются. Для постоянного
хранения новый слой нужно сохранить штатной командой QGIS.

Горячие клавиши действуют только при открытой панели с активным результатом:

- `N` или `Space` — следующий объект;
- `P` — предыдущий объект;
- `S` — разбить текущий объект.

При запуске нового распознавания прежние слои кандидатов удаляются из проекта, но локальные
GeoPackage остаются на диске.

## Типовые ошибки

- `AUTH_FAILED` — проверьте пароль в локальном профиле QGIS.
- `SESSION_EXPIRED` — плагин автоматически повторит вход.
- Нет снимков — сервер не нашёл TIFF, пересекающий AOI.
- AOI не принята — укажите не менее трёх вершин и нажмите «Использовать эту AOI».
- Разбиение отклонено — увеличьте максимальный размер части или исправьте геометрию.
- Нет объектов для выгрузки — уменьшите минимальную площадь или минимальную уверенность.
